# DeliveryIQ-Food-Delivery-Time-Prediction
DeliveryIQ is an end-to-end machine learning platform for intelligent food delivery time prediction. Built with Python, Scikit-learn, Streamlit, and FastAPI, it features model optimization, data auditing, batch CSV predictions, performance evaluation, and automated reporting, achieving a 5.49% reduction in MAE and 6.92% reduction in RMSE.
